### 📝 Descripción
Este programa resuelve un problema de la vida real usando *colecciones en Python*.

*Problema elegido:* Guardar frutas sin repetir.
Para esto uso un *conjunto (set)*, que es perfecto porque no deja que se guarden frutas duplicadas.

### ⚙️ Funcionalidades
El programa cumple todo lo pedido por el docente:

*   *1. Creación de colección:* Inicia con 6 frutas ya registradas.
*   *2. Insertar datos:* Opción para agregar frutas nuevas.
*   *3. Mostrar datos:* Muestra la lista numerada y el total de frutas.
*   *4. Operaciones:* Permite Buscar, Eliminar y Recorrer todas las frutas.

### ▶️ Cómo usarlo
1. Ejecutar el archivo tarea.practica.py
2. Menú interactivo:
   - 1 - Agregar fruta
   - 2 - Mostrar todas
   - 3 - Buscar fruta
   - 4 - Eliminar fruta
   - 5 - Salir
